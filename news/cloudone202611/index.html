米空軍のクラウド基盤「Cloud One」に不正侵入と報道（2026年11月）

最終確認日：2026年11月28日

ロイター通信は2026年11月27日（米国時間）、米空軍の中核のクラウド基盤「Cloud One（クラウドワン）」にハッカーが入り込んだと報じました。時事通信も2026年11月28日にこの報道を伝えています。このページでは、報道で伝えられた事実と、米空軍が以前から公表している Cloud One の説明を分けて整理し、まだ分かっていないことは「現時点で不明」として書いています。

要点（2026年11月28日時点）

  • ロイターによると、Cloud One への侵入は、この1か月ほどの間のシステムを新しくする作業の中で見つかりました。
  • だれが侵入したか、どこまで入られたか、データが持ち出されたかは、現時点で不明です。
  • 米空軍と国防総省は、個別のシステムの状態についてはコメントしないと説明しています。
  • 日本にある米空軍の基地への影響について、2026年11月28日の時点で公式の発表は見当たりません。

何が報じられたか

ロイターの記者2人がワシントンから伝えた記事では、事情を知る3人の話として、米空軍の旗艦的なクラウド基盤である Cloud One が侵入を受けたとされています。侵入が見つかったのは、ここ1か月ほどのあいだに進めていた基盤の更新作業の途中で、見つかったあとは基盤のあちこちで作業に支障が出ていると、2人が話しています。

ロイター自身も、侵入した者がだれなのか、侵入がどこまで広がっているのか、データが盗まれたのかどうかは確かめられていないと書いています。時事通信は、この報道を受けて、情報が外に出たかどうかは現時点で不明で、米軍が被害の全体をつかもうとしていると伝えました。

報道の流れ

  1. 2026年11月27日までの1か月ほどの間Cloud One の更新作業の中で侵入が見つかる出どころ：ロイター（関係者2人の話）
  2. 2026年11月27日ロイターが侵入を報道。米空軍はロイターに声明を出す出どころ：ロイター
  3. 2026年11月27日国防総省の当局者が、時事通信の取材にネットワークの状況はコメントしないと回答出どころ：時事通信
  4. 2026年11月28日時事通信が日本語で報道出どころ：時事通信

「ここ1か月ほど」は報道の言い方で、見つかった正確な日付は公表されていません。

Cloud One とは

Cloud One は、米空軍のライフサイクル管理センター（AFLCMC・マサチューセッツ州のハンスコム空軍基地）が受け持つクラウドの仕組みです。米空軍が2024年9月12日に公開した記事によると、国防総省のアプリを持つ部署がクラウドを使うときの「ひとつの窓口」として作られ、複数の会社のクラウドをまとめて使えるようにしています。秘密（secret）以下の区分のデータを扱うアプリを載せられ、空軍以外の軍のアプリも支えられると説明されています。

これらのアプリのデータに侵入者が触れたかどうかは、報道でも現時点で不明とされています。

止まった作業と影響（報道による）

  • 事務系のアプリを Cloud One に移す作業が止められた（ロイター・関係者3人の話）。
  • すでに Cloud One で動いているアプリの更新ができなくなった（同）。
  • 一部の利用者は、管理者の権限を外された（ロイター・関係者1人の話）。
  • 侵入者はソフトウェアの弱点を使い、基盤全体を操る中枢の部分（コントロールプレーン）に入ったとされる（ロイター・関係者1人の話）。どの弱点が使われたかは特定されていません。
  • 調べている担当者が、米サイバー軍に被害の確認を頼んだ（ロイター・関係者1人の話）。サイバー軍はロイターの問い合わせに答えていません。

米空軍と国防総省の説明

米空軍はロイターへの声明で、個別のネットワークやシステムの安全の状態、弱点、運用の状態にはコメントしないとし、空軍省の情報やシステム、任務の能力を守るための措置を続けていると述べています。国防総省の当局者も、時事通信の取材に対し、運用保全の理由からネットワークの状況にはコメントしないと答えました。2026年11月28日の時点で、米空軍と国防総省の公式サイトに、この件についての発表は見当たりません。

なお、Cloud One の担当者は2024年9月の米空軍の記事で、攻撃者につけ入らせない守りについて「100%の成功率」と話していました。ロイターも、Cloud One の幹部が2023年に同じ趣旨の文章を出していたことを伝えています。
